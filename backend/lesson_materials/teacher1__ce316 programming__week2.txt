register
● A register declaration advises the compiler 
that the variable in question will be heavily 
used. 
● The idea is that register variables are to be 
placed in machine registers, which may 
result in smaller and faster programs. 
● But, compilers are free to ignore the advice.
● The register declaration can only be 
applied to automatic variables and to formal 
parameters of a function. 
static
● The static declaration applied to internal 
variables are local to a particular function 
and they remain in existence rather than 
coming and going each time the function is 
activated. 
● It will be clearer with a demonstration. 
static
● In the function f(), int c is declared each time

● Each time, a new variable c is defined
(created). 
● If we make this variable static, it will only be 
created when the function f() is first called. 
● It will not be deleted and its value will be 
saved.

Real-life recursion: Call waiting
● When you are talking on the phone to A, 
another call comes in. You hold the current

call comes in, and you hold once again and 
switch to C. 
● Once you hang up with C, you return to your 
previous call, B. 
● Similarly, once you hang up with B, you 
return to A.
